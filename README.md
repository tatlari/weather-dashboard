# ⛅ Weather Dashboard

A simple and basic weather dashboard project built with HTML, CSS, and Vanilla JavaScript. It uses the OpenWeatherMap API to fetch and display real-time weather data.

## ✨ Features
* Real-time weather information (temperature, humidity, wind speed).
* Dynamic 3D weather icons based on current conditions.
* Quick search by pressing the `Enter` key.
* Clean and minimal UI.

## 🛠️ Tech Stack
* HTML, CSS, JavaScript (ES6 & Fetch API)
